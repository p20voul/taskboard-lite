\# TaskBoard Lite



Προσωπικός Διαχειριστής Tasks με Scrum-style Kanban Board.



\## Εκτέλεση



Ανοίξτε το αρχείο `index.html` απευθείας στο browser.



\## Χαρακτηριστικά



\- Kanban board με 3 στήλες: To Do / In Progress / Done

\- Drag-and-drop καρτών μεταξύ στηλών

\- Δημιουργία, επεξεργασία και διαγραφή tasks

\- Real-time αναζήτηση

\- Αποθήκευση στο localStorage



\## Τεχνολογίες



\- HTML5, CSS3, JavaScript (vanilla)

\- HTML5 Drag \& Drop API

\- localStorage για persistence
